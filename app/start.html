Or start at a stage

The workflow has four stages. Start at the first one you need.

  1. 1

    Scan

    Pick the vessel out of a CT or MR angiography series and turn it into a 3D surface.

    Start here with a CT or MR scan Open DICOM extraction
  2. 2

    Prepare

    Review the vessel’s openings, set each one as inlet or outlet, and check the units.

    Start here with an STL Open vessel preparation
  3. 3

    Flow

    Mesh the vessel and run the blood-flow simulation, or try a built-in example.

    Start here with a saved case Open the flow solver

    ▶ Run the guided demo

    Thrombosis

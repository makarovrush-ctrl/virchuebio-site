社区准则

  • 切勿发布患者信息。不要发布姓名、出生日期、病历号、扫描文件头或任何其他可能识别个人身份的信息。附加文件前，请检查文件名、截图和导出的文件。
  • 仅限研究讨论。论坛不提供医疗建议，平台的结果不得用于临床决策。
  • 具体而友善。请说明您做了什么、预期是什么，以及实际发生了什么。尊重其他成员及其工作。
  • 帖子是公开的。您发布的任何内容所有人都能看到。涉及保密事项（例如合作或未发表的数据）时，请改为联系团队。

论坛托管在 GitHub Discussions 上，因此 GitHub 的条款和隐私声明也适用于您的帖子。团队负责管理论坛，可能会编辑或删除违反这些准则的帖子。
